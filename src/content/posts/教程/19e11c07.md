本文基于本站实际渲染管线（Astro 7 + Sätteri）逐项实测整理，保证下面的语法都能正常显示。

## 1. 标题

`#` 到 `######` 一共六级标题，渲染后自动带锚点 id，点目录可以跳转。

## 2. 强调

- **粗体**：`**粗体**`
- *斜体*：`*斜体*`
- ~~删除线~~：`~~删除线~~`
- `行内代码`：`` `行内代码` ``

## 3. 引用

> 这是一段引用
> 支持多行

`>` 开头即可，渲染成 blockquote。

## 4. 列表

无序列表：

- 苹果
- 香蕉
- 西瓜

有序列表：

1. 第一步
2. 第二步
3. 第三步

任务列表（GFM）：

- [x] 已完成
- [ ] 未完成

## 5. 链接与图片

链接：[mccsjs](https://mccsjs.cn/)

图片（支持懒加载，鼠标悬停卡片会缩放）：

![示例图片](https://mccsjs.cn/img/ico.jpg)

## 6. 表格

| 语法 | 说明 |
| --- | --- |
| 表格 | GFM 语法，自动生成表头 |
| 代码块 | Shiki 双主题高亮 |
| 脚注 | 文末自动生成注记 |

## 7. 代码块

带语言标识的代码块用 Shiki 高亮，浅色/深色主题自动切换（github-light / github-dark）：

```js
// JavaScript
const greet = (name) => `Hello, ${name}!`;
console.log(greet('世界'));
```

```shell
# Shell
git add .
git commit -m "更新文章"
git push origin main
```

```json
{
  "name": "mccsjsblog",
  "astro": "^7.2.9"
}
```

不写语言也行，照样渲染：

```
纯文本代码块
```

## 8. 脚注

本站支持脚注[^1]，引用处自动生成上标，文末自动生成注记区。

[^1]: 这就是脚注内容，点击上标可以跳到这里。

## 10. 内联 HTML

文章渲染默认放行内联 HTML，因此可以做出一些普通 Markdown 做不到的效果，比如文字颜色：

- <span style="color:red">红色文字</span>
- <span style="color:orange">橙色文字</span>
- <span style="color:#00E09E">青绿文字</span>

也可以直接写 `<blockquote>`、`<center>` 之类的标签做排版。

## 11. 文章 frontmatter 字段

每篇文章开头用 `---` 包裹的元信息，本站支持以下字段：

| 字段 | 含义 | 必填 |
| --- | --- | --- |
| `title` | 文章标题 | 是 |
| `slug` | 链接后缀，8 位 hex | 是 |
| `date` | 发布时间 | 是 |
| `fl` | 分类 | 是 |
| `tags` | 标签 | 是 |
| `zy` | 摘要（首页卡片显示） | 否 |
| `fm` | 封面图 | 否 |
| `zz` | 作者 | 否 |
| `cg` | 草稿标记 | 否 |

示例：

```yaml
---
title: "本站支持的 Markdown 语法"
slug: "19e11c07"
date: "2026-08-29 10:55:00"
fl: "教程"
tags: ["教程", "Markdown"]
---
```

## 12. 其他说明

- 本站使用 **Astro 7 + Sätteri** 渲染管线，默认开启 GFM（表格、删除线、任务列表、自动链接）
- 代码高亮用 **Shiki**，双主题跟随站点浅色/深色切换
- 分类与标签会自动聚合到归档与标签页，无需手动维护

以上就是本站全部已支持的 Markdown 语法，写文章时按需使用即可。
