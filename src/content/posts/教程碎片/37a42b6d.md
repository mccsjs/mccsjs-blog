## 前提
1、有自己的域名  
2、如果使用 [LeanCloud](https://www.leancloud.cn/) 国内版，需要对域名进行备案  
3、如果使用 [LeanCloud](https://leancloud.app/) 国际版，由于 [国际版共享域名不再向中国大陆提供服务](https://forum.leancloud.cn/t/2022-8/25408) ,leancloud 里的应用要绑定一个二级域名  
4、以下内容示例使用的国际版 LeanCloud

## 注册和配置 LeanCloud
直接照搬 Artitalk.js 文档完成操作：
[使用文档 | Artitalk.js](https://artitalk.js.org/doc.html)

1、前往 [LeanCloud 国际版](https://leancloud.app/) ，注册账号。  

## butterfly 主题安装插件和配置使用
### 安装插件

butterfly 主题 Hexo 博客已经整合了 artitalk 功能，所以直接安装 [hexo-butterfly-artitalk](https://www.npmjs.com/package/hexo-butterfly-artitalk) 插件即可：
```bash
npm install hexo-butterfly-artitalk
```
### 默认配置
相关的配置可参考 [Artitalk.js](https://artitalk.js.org/doc.html) 文档
在 hexo 中新建 page 页：
```bash
hexo new page artitalk
```
在index.md中添加以下内容
```md
 <!-- 引用 artitalk -->
 <script type="text/javascript" src="https://unpkg.com/artitalk"></script>
 <!-- 存放说说的容器 -->
 <div id="artitalk_main"></div>
 <script>
 new Artitalk({
     serverURL: 'https://域名',// Your LeanCloud site
     appId: '', // Your LeanCloud appId
     appKey: '', // Your LeanCloud appKey
     color1: 'linear-gradient(45deg,rgba(109,208,242,0.75) 15%,rgba(245,154,190,0.75) 85%)',
     color2: 'linear-gradient(45deg,rgba(109,208,242,0.75) 15%,rgba(245,154,190,0.75) 85%)',
 })
 </script>
 ​
```


登录LeanCloud创建应用
名称随意，选择开发版，然后创建，点击设置
## 绑定域名
打开 [LeanCloud](https://leancloud.app/) artitalk 应用左边菜单栏的设置 - 域名绑定，添加一个二级域名，如下图：

<img src="https://youke1.picui.cn/s1/2025/10/25/68fc652e54f88.png" alt="image" style="zoom:60%;" />

## 创建用户
点击左侧内建账户，用户管理，添加用户
tips：点击非必填，在img项添加你头像的链接

## 部署LeanCloud
1. 点击结构化数据➡️_User表➡️添加行
此为在博客页面登录artitalk所用的账号密码
<img src="https://csjs.eu.org/jc/1.jpg" alt="image" style="zoom:60%;" />
2. 修改权限为刚才添加的用户
<img src="https://csjs.eu.org/jc/3.jpg" alt="image" style="zoom:60%;" />
3. 创建Class➡️shuoshuo➡️修改访问权限为刚才创建的用户
<img src="https://csjs.eu.org/jc/5.jpg" alt="image" style="zoom:60%;" />
4. 创建Class➡️atComment➡️访问权限为所有用户
<img src="https://csjs.eu.org/jc/2.jpg" alt="image" style="zoom:60%;" />
5. 点击应用凭证，记下AppID和AppKey的值
<img src="https://csjs.eu.org/jc/4.jpg" alt="image" style="zoom:60%;" />
6. 设置➡️安全中心➡️Web安全域名，填入自己的博客域名
<img src="https://youke1.picui.cn/s1/2025/10/25/68fc8da6272b2.png" alt="image" style="zoom:60%;" />
