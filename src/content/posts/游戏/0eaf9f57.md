# 前情提要
我和我的三位小伙伴（<span style="color:red">小红</span>、<span style="color:orange">小橙</span>、<span style="color:#00E09E">小绿</span>）组团坐飞机去牛尔代夫玩耍。
![PEAK Screenshot 2026.08.22 - 21.45.53.16.png](https://i.seln.cn/file/picui/00MlxMup.png)

我们正在期待着检票登机，留下了我们并不完美的合照
![PEAK Screenshot 2026.08.22 - 21.46.04.50.png](https://i.seln.cn/file/picui/iRnw0hEY.png)

【**小橙**：这个机场居然还有篮球场哎】
于是我们就在候机厅打起了篮球，边打边等检票。打完没多久飞机开始检票，我们拿着专属票上了飞机。
![PEAK Screenshot 2026.08.22 - 21.46.53.61.png](https://i.seln.cn/file/picui/GOkuessE.png)

飞机上大家都在幻想牛尔代夫的好日子，盘算吃啥穿啥玩啥，谁也没料到接下来发生的事——<span style="color:red">飞机坠机了！</span>
![PEAK Screenshot 2026.08.22 - 21.47.20.76.png](https://i.seln.cn/file/picui/280zj9S6.png)

我是最后一个醒来的，整架飞机只剩我们 4 人活下来。醒来时伙伴们已经认清现实开始行动，只有小绿还沉浸在震惊与恐慌之中，半天没回过神来。

# 海岸
我们坠落在了荒岛上，我们搜罗了地面和飞机里还能使用的工具
![PEAK Screenshot 2026.08.22 - 21.48.34.57.png](https://i.seln.cn/file/picui/Ed2wFGzk.png)
我拿到了一瓶能量饮料，还有半块椰子，小绿拿到了一块超级大的棒棒糖🍭，据她所言，舔一口会感觉全身充满使不完的力气。小橙去翻剩下的行李箱，他想找到点有用的东西。翻半天就摸出一副旧手套，聊胜于无。

我们面前是一座高山，差点没过云朵。山顶有炊烟，我们不知道那里有什么，但有炊烟证明那边有人或者来过人，我们无路可退，只能咬牙前进。

![PEAK Screenshot 2026.08.22 - 21.50.10.42.png](https://i.seln.cn/file/picui/3IESQ39i.png)
当我来到山脚，抬头望时，我才发现自己的渺小。我有点打了退堂鼓，400多米的高山，我们真的能爬上去吗？
山间纵横着很多吊桥，这里一定来过人！我们克服了对高山的恐惧，开始慢慢向上爬。

![PEAK Screenshot 2026.08.22 - 21.54.23.49.png](https://i.seln.cn/file/picui/hPmWCeWL.png)
不得不说小绿和小红真是勇敢，面对未知的处境，她们总是冲在最前方。
及其细小的锁链钉在山间，我佩服他们的勇气，当我还在原地驻足时，他们已经攀爬到一半了。
*他们真的不怕吗，要是稍微有点差错就是万丈深渊！
在我自己和伙伴们的鼓励下，我也克服恐惧向上爬。

终于在不懈努力下，我们爬到了山巅
![PEAK Screenshot 2026.08.22 - 21.58.35.73.png](https://i.seln.cn/file/picui/jFNHZgG7.png)
我们爬到了山巅，这里只有熄灭的篝火，有人给我们留了食物？
我们肯定的是：`这边的人前不久才离开的`

突然，小绿指着远方说：<span style="color:#00E09E">你们看那边，是我眼花了吗，那里出现了新的高山</span>![PEAK Screenshot 2026.08.22 - 21.59.20.55.png](https://i.seln.cn/file/picui/w6H7pyUG.png)
我们抬头望去，我们无一不惊讶
刚刚还是雾气缭绕的环境，雾气不知何时散去，留下了另一座高山。我们知道，故事还没结束
无论如何，我们已无法后退，只能咬牙前进，登上这座“`雨林`

# 雨林
![PEAK Screenshot 2026.08.22 - 22.00.01.23.png](https://i.seln.cn/file/picui/OQToEGZT.png)在篝火旁稍作休息后，我们凑近跟前瞧，这好像是一片未经污染的生态园，地面上很多苔藓，湿滑湿滑的。
在前一座山上我们已经爬出了信心，我们甚至在第二座山中比谁登顶速度最快，所以我们分开走了。这是我们做过最错误的决定。
![PEAK Screenshot 2026.08.22 - 22.07.47.13.png](https://i.seln.cn/file/picui/h8BaYv9g.png)
当我爬到半山腰时，回望走过的路，我居然已经领先他们太多，这导致我信心异常膨胀，于是我加速向上爬。

突然之间，下雨了，本就潮湿黏糊的地面更加抓不住了。我在这时已经慌了，我的体力已经不多，只能祈求这场雨快点过去。雨越下越大，我连头顶的落脚点都看不清了。

我缓慢的向上攀爬，终于！

天无绝人之路，就差一步！就差一步我就能登上平台，就差一步我就能稍作休息。

可惜没有如果，树上落下一颗巨大的蜂窝，一堆虎头蜂钻出来，蜂群如黑烟封住所有向上的空隙，而我脚下，是空无一物的深渊。

`原来老天给我留的路，就是这条刚好够我绝望的窄缝。`

![PEAK Screenshot 2026.08.22 - 22.12.17.40.png](https://i.seln.cn/file/picui/ZsrrGygP.png)我最终还是坠落了，我甚至感受到灵魂离体的过程。周围静悄悄，没人知道这里躺了个人。
我静静等待死亡的来临，就在我灵魂完全离体的时候，我听到了熟悉的、同伴的声音
![PEAK Screenshot 2026.08.22 - 22.16.25.66.png](https://i.seln.cn/file/picui/ByTqfiN1.png)
我不知道是什么情况，我的灵魂好像依附在了同伴的身上，我能看着我的伙伴们继续前行。我认为这样的结局不算凄惨，至少我能看到他们。

但是，厄运比我们想象的更快到来，小绿坠崖了！
![PEAK Screenshot 2026.08.22 - 22.21.55.67.png](https://i.seln.cn/file/picui/zFRXYozA.png)这种感受说不上来，我竟然完整的看了同伴死亡的全过程
但庆幸的是，小绿也化身灵魂依附在同伴身上了，我们能互相看到彼此。这让我不是那么孤独了。

![PEAK Screenshot 2026.08.22 - 22.27.19.75.png](https://i.seln.cn/file/picui/mB2pfSZf.png)在我和小绿的注视下，小红爬到了山巅，吹响了胜利的号角
![PEAK Screenshot 2026.08.22 - 22.28.42.62.png](https://i.seln.cn/file/picui/sVWaLdJo.png)这里有个很奇怪的雕像，当小红靠近这里时，我们脑海中都出现了一个概念：

这雕像能复活死去的人！

![PEAK Screenshot 2026.08.22 - 22.30.21.12.png](https://i.seln.cn/file/picui/ntzmdHE1.png)
我们复活了，复活也有代价，我和小绿明显感知我们的身体状态和体能被削减了一部分
但是相对于生命而言，这点代价微不足道。

当我们还在为死而复生而感到高兴时，远处的雾散去了，留下了一座大雪山。

我们都没有为此惊讶山顶没有任何能帮我们逃离荒岛的东西，肯定还有前路。

不过刚淋完雨，又要爬雪山，我们打算扎营地休整后出发。
![PEAK Screenshot 2026.08.22 - 22.36.23.26.png](https://i.seln.cn/file/picui/TJesbQti.png)
# 雪山
这个雪山和想象中一样，天气混乱异常
每2分钟都会刮大风下大雪，这时候我们就得躲进地道躲雪。躲雪时我们四个挤成一团搓手取暖，小绿还分了口棒棒糖给我。风雪一停就得赶紧冲，赶在下场大雪前多爬一段。
![PEAK Screenshot 2026.08.22 - 22.39.12.61.png](https://i.seln.cn/file/picui/V0Q5Ersw.png)

# 雾沼![PEAK Screenshot 2026.08.22 - 22.53.42.64.png](https://i.seln.cn/file/picui/Ne0Cjmi1.png)
在前面几天的经验下，我们有惊无险的通过了雪山

出现在我们面前的是一片弥漫紫色雾的地方，远处是一个高塔。这雾有毒，待久了体力掉得飞快，我们全程憋着气赶路。

我们都有预感，高塔上有让我们离开孤岛的方法

![PEAK Screenshot 2026.08.22 - 23.07.04.29.png](https://i.seln.cn/file/picui/pNy7xBzz.png)

# 城塞
又是波澜不惊的几天，我们穿过了有着毒雾的沼泽
不知为什么，总有怨灵想拖我们下水。我们加速离开了那里（实际上是我忘记截图了）

![PEAK Screenshot 2026.08.22 - 23.08.27.50.png](https://i.seln.cn/file/picui/1X0QAnPA.png)
这大概率就是我们最后一站了。
这城堡的难度比前面几座山加起来都高。小橙在这摔了三次，第三次是被电锯追着跑，他边跑边喊救命，我们在上面笑疯了。
![PEAK Screenshot 2026.08.22 - 23.09.14.26.png](https://i.seln.cn/file/picui/IivDWliu.png)
纵横交错的锁链，墙面隐藏的发射器，挂在墙上的电锯。不断旋转的滚🔪
我不知道能不能通关，但是。`我们都在用力的活着`
